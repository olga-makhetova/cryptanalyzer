# cryptanalyzer
Итоговый проект к модулю Java Syntax. Пишем криптоанализатор Задача: написать программу, которая работает с шифром Цезаря

Графическая часть выполнена с помощью Swing. 
Пользователь выбирает два текстовых файла: для источника и для результата. 
Программа предоставляет три возможности:
1. Шифрование текста с заданным ключом
2. Расшифровка текста с заданным ключом
3. Расшифровка текста без ключа методом brute force
